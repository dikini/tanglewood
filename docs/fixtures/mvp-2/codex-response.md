## A quieter research workspace

Keep the **document at the centre**. Use `Research/<topic>/` for findings, then attach the report to a **Work** thread when you are ready to act.

- Read the selected notes and compare sources.
- Save a short report with useful citations.
  - Keep the original authored notes intact.
  - Link the report and its sources.

| Profile | Purpose |
| --- | --- |
| Research | Find evidence and write notes |
| Work | Use that context to carry out a task |

> A project is a vault. Threads share that project; their attached context stays explicit.
